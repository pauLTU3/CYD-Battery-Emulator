CYD Battery Emulator

Install the latest firmware on an ESP32-2432S028R directly from your browser.

  1. Use Google Chrome or Microsoft Edge on a desktop computer.
  2. Connect the CYD with a USB data cable.
  3. Click the install button and select the CYD serial port.
  4. Choose Erase device when installing for the first time.
Web Serial is not available. Open this page in Chrome or Edge.

If connection fails, hold the BOOT button while connecting and release it when flashing starts. After installation, connect to BatteryEmulator-CYD Wi-Fi and open 192.168.4.1 to configure the display.
